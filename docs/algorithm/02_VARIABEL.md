# Belajar Lontara-Lang: 2. Deklarasi Variabel (`taroi` / `ᨈᨑᨚᨕᨗ`)

Variabel alokasi data menggunakan kata kunci `taroi` (Bugis Latin) atau `ᨈᨑᨚᨕᨗ` (Aksara Lontara) diikuti oleh nama variabel, operator penetapan `=`, dan nilai.

---

## Sintaksis

### Versi Bugis Latin
```lontara
taroi umur = 25;
taroi nama = "Lontara";
taroi aktif = tongeng;
```

### Versi Aksara Lontara
```lontara
ᨈᨑᨚᨕᨗ angka = 42;
```

---

## Tipe Data yang Didukung

1. **Integer**: Bilangan bulat (misal: `10`, `-5`).
2. **String**: Teks diapit tanda petik ganda (misal: `"bugis"`).
3. **Boolean**: Nilai logika `tongeng` (true) dan `banna` (false).
