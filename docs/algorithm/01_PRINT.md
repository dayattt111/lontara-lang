# Belajar Lontara-Lang: 1. Cetak Konsol (`paui` / `ᨄᨕᨘᨕᨗ`)

Fungsi `paui` (Bugis Latin) atau `ᨄᨕᨘᨕᨗ` (Aksara Lontara) digunakan untuk mencetak nilai masukan ke terminal atau konsol luaran.

---

## Sintaksis

### Versi Bugis Latin
```lontara
paui("Halo, Dunia!");
paui(100 + 200);
```

### Versi Aksara Lontara
```lontara
ᨄᨕᨘᨕᨗ("salama");
ᨄᨕᨘᨕᨗ(42);
```

---

## Banyak Argumen

Anda dapat mengirim beberapa argumen yang dipisahkan dengan koma `,`:

```lontara
paui("Nilai X:", 10, "Nilai Y:", 20);
```
